#  Projects

Larger, end-to-end builds worth keeping and showing off.

**What belongs here (vs. `../experiments/`):**
- Has a clear goal and a working result.
- Structured enough to revisit months later.
- Often combines multiple skills (data + model + evaluation + maybe a UI).

**Suggested layout:** one folder per project, each with its own `README.md`, requirements, and clear run instructions.
