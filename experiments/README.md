#  Experiments

A scratch space for quick trials, proofs-of-concept, and throwaway ideas.

**Rules of the sandbox:**
- Anything goes — this is for *trying things*, not polished material.
- Name experiments descriptively (e.g. `2026-01_rag-prototype/`).
- If something graduates into a real build, promote it to `../projects/`.
- If it teaches a lesson worth keeping, distill it into `../notes/`.
