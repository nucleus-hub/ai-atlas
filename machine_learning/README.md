#  Machine Learning

Classic (non-deep) machine learning: theory and hands-on implementations.

| Folder | Focus |
|--------|-------|
| `fundamentals/` | Core concepts: bias/variance, train/test split, cross-validation, metrics, overfitting |
| `algorithms/` | Implementations: linear/logistic regression, decision trees, SVM, k-means, kNN, ensembles |

**Toolkit:** [scikit-learn](https://scikit-learn.org/) · pandas · NumPy · matplotlib

> Tip: pair each algorithm with a small dataset and an evaluation write-up in `../notes/`.
