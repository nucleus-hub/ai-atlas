# Deep Learning Basics Demo Notebook

This workspace contains demo notebooks for learning deep learning concepts and working with neural networks in Python.

## Included Notebooks

- `Demo_I_Neural_Network_Learning_in_Action.ipynb`
  - Introduction to neural network learning and fundamental concepts.

- `Demo_II_Neural_Networks_in_Action.ipynb`
  - Practical examples and demonstrations of neural network architectures in action.

- `MNIST Handwritten Digit Classification with TensorFlow Keras.ipynb`
  - A hands-on notebook for classifying handwritten digits using the MNIST dataset and TensorFlow Keras.

## How to Use

1. Open the notebook in Google Colab or Jupyter.
2. Follow the notebook cells in order.
3. Run the cells to train models, explore datasets, and learn concepts interactively.

## Open in Jupyter Notebook

1. Open PowerShell in this folder.
2. Activate your Python environment if you have one.
3. Run `jupyter notebook`.
4. In the browser, open one of the notebook files.

## Open in Google Colab

1. Go to https://colab.research.google.com.
2. Choose `Upload` and select a notebook file from this folder.
3. Alternatively, use `GitHub` and paste your repository URL if the repo is public.

## Notes

- Ensure you have a Python environment with the required deep learning packages installed (e.g., `tensorflow`, `numpy`, `matplotlib`).
- If using VS Code, install the Python and Jupyter extensions for notebook support.
